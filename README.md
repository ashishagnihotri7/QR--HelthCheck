# QR-HealthCheck

## 🏥 Project Description
**QR-HealthCheck** is a blockchain-based health record verification system.  
It allows users to create, update, and verify health records securely using a QR code as a unique identifier.  
Each record is stored immutably on the blockchain, ensuring transparency and authenticity.

---

## 🎯 Project Vision
To create a decentralized, tamper-proof health record management system that empowers individuals and healthcare institutions to share and verify medical data securely through QR codes.

---

## ✨ Key Features
- **QR-Based Record Identification:** Each user’s health record is tied to a unique QR hash.  
- **Immutable Data Storage:** Health status and timestamps are stored permanently on-chain.  
- **Easy Verification:** Anyone can verify the authenticity of a health record using a QR hash.  
- **User Ownership:** Only the owner of a record can modify their health status.
